# GitHub release checklist

1. Create a repository such as `setr-m2`.
2. Upload the **contents** of this package, not an extra nested folder.
3. Keep `restricted_inputs/` documentation but do not commit restricted input CSVs.
4. Edit `CITATION.cff` placeholders.
5. Commit with message `Public reproducibility release v1.0.0`.
6. Create tag `v1.0.0` and a GitHub Release.
7. Connect the repository to Zenodo and archive the release.
8. Put the resulting Zenodo DOI badge in README only after DOI activation.

Suggested short description: `Frozen reproducibility materials for SETR, a controlled English–Thai scholarly translation stress-test benchmark and multi-signal evaluation framework.`
